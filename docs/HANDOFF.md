# Publication checkpoint — Words and practice cleanup

This source candidate is based on the published Dice checkpoint
`8e5e721c31e7d2aa09e093e7b4dd8d5bc39db1de`. It adds native Words validation,
prefix selection, taller layout, practical Clear, common Safety/About and the
Words-only idle/wake/orbit lifecycle. See [WORDS-MILESTONE](WORDS-MILESTONE.md).

## Installed image is not this candidate

The separately installed practice-cleanup source image has recorded scoped
source/security, visual, sanitizer, target and startup gates, app-only readback
and boot verification. **Current physical UI/touch/computation acceptance remains
pending.** Historical observations on earlier images do not transfer to it or to
a new checkout build. This candidate has not been flashed; publication adaptation
makes it a different source/build identity.

This checkout does not distribute device evidence, logs, binaries, backups, user
inputs or identifiers. Retained original evidence is not rebuilt or overwritten.
Host tests establish only their named public-fixture contracts, not target memory,
physical contact behavior, performance, reproducibility or funded-wallet safety.

- Independent source/security and publication content/privacy/license reviews
  passed for the bounded source candidate. No real-secret or hardware approval.
- Separately close public-fixture scrolling, eligible idle, wake-over-actions,
  held/overlapping contact and normal next-contact checks.
- Preserve result-specific no-funds, weak-input and checksum-not-quality warnings.
  Clear is selected-mode, best-effort owned input/result cleanup; compiler
  temporaries, crypto internals, old allocations and full RAM are excluded.
