# Known limits

- Experimental educational/public-practice calculator. Never use real secrets or funds. Not a wallet, signer, certified RNG or independently certified secure product.
- Bounded independent source review and complete fresh host suite passed. Complete target image, physical acceptance, install/update/recovery and release gates remain pending.
- D6 RAW and Coleman encode different transcripts. Hashing does not create entropy. Fairness/independence of physical outcomes cannot be inferred from checksums, output width or a fingerprint.
- Clear is bounded application cleanup, not proof that stacks, allocator remnants, crypto temporaries, caches or RAM contain no prior copies. Saver conceals state; it is not a wipe or lock.
- No proven physical air gap; board includes a wireless-capable ESP32-C6 companion. No companion firmware changes are part of this release work.
- Only the named Waveshare board and Rev1.x target profile are in scope; other boards, Rev3.x, mobile browsers, macOS/Windows flashing and browser P4 recovery have no candidate-specific acceptance.
- No binary reproducibility certification, signed release manifest, published recovery asset or working browser installer is claimed.
- Upstream custom license and third-party notices apply. Attribution is not endorsement; binary/logo redistribution scope needs independent review.
