# Agent instructions

Own only your assigned checkout and task scope. Never touch attached hardware,
flash, create remotes, publish, or contact contributors without explicit approval.
Never read private backups to construct fixtures. Public vectors only; no signing,
real-secret input, persistence, RNG or networking additions.

Run scripts/test-host.sh for changes. Preserve the exact custom upstream license,
Cargo locks, component lock and provenance. Never claim target build or hardware
PASS from host tests. Record real verification and remaining gaps. Keep generated
artifacts and local caches ignored. Review staged content for private paths, device
identifiers, credentials and license coverage before every publication proposal.
The target fixture and host extraction are different implementations; do not imply
that the complete upstream app runs on device. GUI mockups are not hardware evidence.
